# Reporting a vulnerability

Use [GitHub's private vulnerability report](https://github.com/Dyluhn/festavia-studio/security/advisories/new)
for a suspected credential exposure, authentication bypass or other security
issue. Do not include credentials in a public issue. Ordinary functional bugs
and hardware compatibility reports belong in the repository's issue forms.

Include the project version, edition, relevant firmware versions, a description
of the impact and minimal reproduction steps. Redact Wi-Fi passwords, bridge
application keys, device tokens, private connection files and household details.
Share a sanitized diagnostic only when it helps reproduce the problem.

The current public beta is the supported development line. Security fixes will
be published as new project releases with separate image versions when needed.
This is a community project without a guaranteed response time.
